# 🎁 ReflexCoin Quick Reference — Contribution Types & Rewards

**Fast lookup**: How much can I earn, and what counts as a contribution?

## 💻 Code & Development

| Contribution | RFX Range | Hours | Notes |
|--------------|-----------|-------|-------|
| **Bug fix** | 50–200 | 1–5 | Simple to moderate complexity |
| **Feature** (small) | 200–500 | < 10 | Single feature, well-defined scope |
| **Feature** (medium) | 500–2,000 | 10–40 | Multi-part feature, documented |
| **Feature** (large) | 2,000–5,000 | > 40 | Major system, significant complexity |
| **API integration** | 1,000–3,000 | 20–50 | Google Gemini, HuggingFace, etc. |
| **Infrastructure** | 1,000–5,000 | 20–100 | CI/CD, deployment, database setup |
| **Documentation** | 100–500 | 5–20 | README, guides, API docs |
| **Code review** | 25–100/review | 0.5–2 | Mentoring, feedback on PRs |
| **Security audit** | 500–2,000 | 5–30 | Vulnerability testing, fixes |

### Developer Examples
- ✅ Fixed navbar bug (2 hrs) → 75 RFX
- ✅ Integrated Google Image API (35 hrs) → 1,500 RFX
- ✅ Rewrote documentation (12 hrs) → 250 RFX

## 🌟 Bonus Multipliers

Apply these to increase your reward:

| Bonus | Multiplier | When It Applies |
|-------|-----------|-----------------|
| **Papiamentu-first** | +10% | Content primarily in Papiamentu |
| **Bilingual** | +5% | English + Papiamentu equally |
| **Accessibility** | +20% | WCAG AA, inclusive design, captions |
| **Innovative** | +25% | Novel approach, first of its kind |
| **Community nominated** | +15% | 3+ people suggest high impact |
| **Open source** | +10% | Publicly licensed, reusable code |
| **Teachable moment** | +15% | Includes clear explanation/learning |
| **Early Phase 1** | +20% | Contributions in first 2 months |

### Multiplier Examples
- Papiamentu beginner's guide (250 RFX base) + accessibility (+20%) + Papiamentu (+10%) = **325 RFX**
- Google Gemini integration (1,500 RFX base) + innovative (+25%) + open source (+10%) = **2,175 RFX**

## ❌ What Does NOT Earn RFX

- ✗ Commenting on issues (unless substantial code review)
- ✗ Reporting bugs without proposed fix
- ✗ Discussions/debates in Slack or GitHub
- ✗ Retweets, likes, shares (social media)
- ✗ General community participation (unless roles above)
- ✗ Copied/plagiarized work
- ✗ Spam or low-effort contributions

## 🎯 Submit Your First Contribution

1. **Pick** contribution type from this guide
2. **Create** your work with quality in mind
3. **Prepare** metadata.json sidecar
4. **Open GitHub issue**:
   ```
   Title: 📢 ReflexCoin: [Type] — [Your Title]
   Body: [Include metadata.json]
   ```
5. **Wait** for validation (3–5 days)
6. **Celebrate** when approved! 🎉
