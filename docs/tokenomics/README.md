## 🎯 Quick Start

### I want to earn ReflexCoin. What do I do?

1. **Choose your role**: 
   - 💻 Developer (code, infrastructure, technical)
   - 🎨 Creator (art, prompts, design)
   - 📚 Educator (courses, tutorials, workshops)
   - 🗳️ DAO member (governance, moderation, audits)

2. **Pick a contribution** from [QUICK_REFERENCE.md](QUICK_REFERENCE.md)
   - E.g., "Write documentation" → 100–500 RFX
   - E.g., "Design logo" → 300–1,500 RFX

3. **Create your work** with quality & care
   - Follow [CODE_OF_CONDUCT.md](../../CODE_OF_CONDUCT.md)
   - Create metadata sidecar JSON
   - Test/verify before submission

4. **Submit for validation** on GitHub:
   ```
   Title: 📢 ReflexCoin: [Type] — [Your Title]
   Body: Paste metadata.json + links
   ```

5. **Wait for approval** (3–5 days typical)
   - Initial review (24–48h)
   - Quality audit (3–5 days)
   - Ethics validation (1–2 days)
   - DAO vote (if > 500 RFX)
   - Token distribution

6. **Celebrate!** 🎉
   - Tokens credited to your account
   - Public record created (anonymized)
   - You've supported Reflexhon's mission

## 🔒 Ethics & Validation

All contributions must pass:

✅ **Quality Check**
- Functional, well-documented, tested
- Meets project standards

✅ **Ethics Audit**
- No discrimination or bias
- Respects local languages & culture
- No harmful content
- Transparent sources

✅ **Originality Verification**
- No plagiarism
- Proper licensing
- Clear attribution

✅ **DAO Voting** (for large contributions > 500 RFX)
- Community approves value
- Transparent decision-making

## 📊 Treasury (20% Fund)

Monthly earnings are allocated:
- **10%** → Education programs (Papiamentu AI workshops, local hubs)
- **30%** → DAO operations (voting incentives, governance)
- **25%** → Infrastructure (servers, API costs, tools)
- **20%** → Community outreach (events, partnerships)
- **10%** → R&D (innovation, new features)
- **5%** → Emergency reserve

**Example month**: 10,000 RFX distributed
- Treasury receives: 2,000 RFX
- Education gets: 200 RFX → Local workshops
- Infrastructure gets: 500 RFX → Hosting upgrades

## 💭 Guiding Principles

**ReflexCoin is built on:**

1. **Creator-First** — 80% of earnings to contributors
2. **Ethical** — Bias audits, no harm, cultural respect
3. **Transparent** — Public records (anonymized), DAO votes visible
4. **Sustainable** — Value-backed, not speculative
5. **Inclusive** — Papiamentu-aware, low barrier to entry
6. **Human-Centered** — Tokens reward human contribution, not just code
