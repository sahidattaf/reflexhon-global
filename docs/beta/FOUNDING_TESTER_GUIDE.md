# Founding Tester Guide — Reflexhon Public Beta

Thank you for joining Reflexhon's Phase 2A founding tester cohort. This is a 14-day, invite-only learning program capped at 25 testers. This guide explains how to access the beta, what to try, how to evaluate it, and how to send feedback.

## Before you start

- **Reflexhon can make mistakes.** Responses are experimental and should be reviewed by a person, especially for cultural, educational, legal, medical, or financial use.
- **Do not submit sensitive information.** Do not enter passwords, financial details, health information, government IDs, or anyone else's personal data into the chat, forms, or GitHub issues.
- **Participation is not compensated.** Joining this beta creates **no financial entitlement, payment, equity, token, point, or reward of any kind**, now or in the future. There is no ReflexCoin, ReflexPoints, or wallet associated with this program.

## How to access the public beta

Open the Reflexhon Studio public beta UI:

- <https://reflexhon-global.sahidattaf.workers.dev/studio> (or the root URL, `https://reflexhon-global.sahidattaf.workers.dev/`)

You will see a **PUBLIC BETA** badge and a mistakes/limitations notice at the top of the page. Read it before testing.

## Three recommended demo prompts

Try these first — they are also available as one-click prompt chips in the chat tab:

1. `Kiko ta empatia?` — a basic Papiamentu comprehension check.
2. `Splika respeto den contexto di Curaçao.` — a cultural-context check specific to Curaçao.
3. `Tradusí 'community care' na Papiamentu natural.` — a translation-naturalness check.

After trying the three, feel free to test your own prompts in Papiamentu, English, or code-switched text using the language and island-context selectors in the sidebar.

## How to evaluate what you see

For each response, consider:

| Dimension | Ask yourself |
|---|---|
| Language | Is the Papiamentu (or English) grammatically natural, not just technically correct? |
| Cultural context | Does it fit the island context you selected (Aruba, Bonaire, Curaçao, or general)? Does it wrongly generalize the three islands as one culture? |
| Usefulness | Would this response actually help someone in the situation you tested? |
| Usability | Was it clear how to use the chat, dataset explorer, and feedback links without help? |

You don't need every response to be perfect — the goal is to find where it's wrong or unclear so it can be corrected.

## Human-review reminder

Nothing in this beta is verified professional, legal, medical, or financial advice. Every response should be treated as a draft a human should check, especially before acting on it or sharing it further.
